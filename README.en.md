## ⚡ Quick Start for Windows

1. **Download:** Get the latest portable `.zip` from **[Releases](https://github.com/ducanhcah/threads2video_ducanhcah/releases/latest)**.
2. **Extract:** Extract the zip anywhere on your PC.
3. **Run:** Double click **`CHAY.bat`**.
4. **Create:** Paste your Threads link $\rightarrow$ Pick a preset (*⚡ Fast Viral*, *☕ Story*, or *🤣 Comedy*) $\rightarrow$ Click **CREATE VIDEO**.
